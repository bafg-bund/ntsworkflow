# Combine a formula with the adduct

Combine a formula with the adduct

## Usage

``` r
correct_formula(formula, adduct)
```

## Arguments

- formula:

  Chemical formula as a string

- adduct:

  adduct as a string, must be one of \[M+H\]+, \[M+Na\]+, \[M\]+,
  \[M-H\]-, \[M+NH4\]+, \[M+H2CO2-H\]-, \[M-H2O+H\]+

## Value

List with two elements: formula with the adduct added to it and the
charge
