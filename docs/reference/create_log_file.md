# Create a list for logging when processing with the Non-Target App

Using variables in the global environment in the Non-Target-App, a
\`list\` is created which is later saved as a log file in JSON format
when saving the processing results.

## Usage

``` r
create_log_file()
```

## Value

list with used settings for peakpicking, alignment, blankcorrection,
normalization, filtering, annotation
